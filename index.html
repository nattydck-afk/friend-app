เชื่อมต่อฐานข้อมูล Google Sheet

ซิงค์ข้อมูล Real-time 2-Way (อ่าน + เขียน)

🟢 การอ่านข้อมูล Real-time: เชื่อมต่อสำเร็จ
แอปดึงข้อมูลสดจากชีต SumView, จัดการรายการ, เรียกเก็บ ผ่าน Google API อัตโนมัติ (ไม่มี CORS Error)
🔗 ลิงก์ Google Sheet ของคุณ: คลิกเปิด Google Sheet ↗
💡 วิธีติดตั้งเพื่อเขียนข้อมูลกลับชีตจริง (2-Way):
1. เปิด Google Sheet แล้วไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
2. ก๊อปปี้โค้ดในไฟล์ google-apps-script.js ไปวางแทนที่โค้ดเดิม
3. กด Deploy > New deployment เลือกประเภท Web app
4. ตั้งค่า Execute as: "Me" และ Who has access: "Anyone"
5. กด Deploy แล้ว Copy "Web app URL" (ลงท้ายด้วย /exec) มาวางในช่องนี้
