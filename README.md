# 🐷 Friend App (แก๊งค์ลูกหมู ✈️)

เว็บแอปพลิเคชันบริหารจัดการทริปและการเงินเพื่อนๆ แก๊งค์ลูกหมู
เชื่อมต่อฐานข้อมูลสดกับ Google Sheet แบบ 100%

## ✨ ฟีเจอร์หลัก
- 🗺️ บันทึกและไฮไลท์จังหวัดที่เคยไปแล้วบนแผนที่ประเทศไทย (SumView)
- 💰 คิดตังค์ & หารเงินกองกลาง (เรียกเก็บ)
- 🧾 แนบสลิป & สรุปสถานะการโอนเงิน
- 📊 สรุปงบทริป: มีตังค์ / ใช้ตังค์ / เหลือตังค์
- 🔐 ระบบ PIN 4 หลักแยกโปรไฟล์สมาชิก 6 คน (แอดมิน + สมาชิก)

## 🚀 การ Deploy บน Vercel
โปรเจกต์นี้พร้อมใช้งานบน Vercel ทันที:
1. นำโฟลเดอร์นี้ขึ้น GitHub
2. เชื่อมต่อ Repository ใน Vercel Dashboard
3. กด Deploy ได้ทันทีโดยไม่ต้องตั้งค่า Build Command เพิ่มเติม
